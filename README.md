**代表项目**

- [**VizJudge**](https://github.com/hengbolei/VizJudge)：判断哪些图表真正对建模任务有信号，并把证据转化为机器学习的下一步行动；支持 CLI、Python API，也可以作为 MCP server 供宿主 Agent 调用。
- [**provenance-care-note**](https://github.com/hengbolei/provenance-care-note)：以溯源为核心的临床护理记录原型，包含基于角色的访问控制、可解释的优先级、审计历史和 PHI 脱敏，使用合成数据。
- [**uk-road-collision-severity-prediction**](https://github.com/hengbolei/uk-road-collision-severity-prediction)：基于英国交通部 50 多万条记录，对严重道路碰撞做时间外预测，比较五种分类器，并做漂移和校准分析。
- [**fractional-tde-classification**](https://github.com/hengbolei/fractional-tde-classification)：利用基于 FFT 的分数阶特征，对 LSST 风格光变曲线中的潮汐瓦解事件进行分类。
